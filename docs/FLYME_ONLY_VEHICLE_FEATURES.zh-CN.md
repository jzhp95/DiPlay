# Flyme 版本的车辆功能边界

本版本已移除比亚迪专用设置及其自动运行入口。此清理不修改 MFi、USB／无线连接、AirPlay 音视频、Flyme EAS 注册与焦点释放、Siri 请求和日志导出协议。

移除项目：

- 比亚迪导航／HUD、原车仪表歌曲和通话卡片、比亚迪专用通话按键。
- DiLink 4 ADB 仪表、平台21窗口、原车地图接管、DiLink 5.1 仪表主题和小窗自动监听。
- 比亚迪车辆数据读取、旧车型探测、车辆速度／挡位／电池／充电状态上报、胎压与仪表读速。
- 比亚迪方向盘摇杆、地图缩放和短语音键屏蔽配置；保留通用 Siri 按键配置与 Flyme 231／200231 接入。
- 原车来电弹窗抑制、通过 Telecom 接管车机电话音频、车辆氛围灯律动。
- 比亚迪 ADB 热点授权界面、启动修复和比亚迪设置组件跳转。

旧偏好仍可能存在于 Android 私有数据中，但对应读取接口固定返回关闭，不会因升级、重启或连接手机而重新启用。通用开机启动改用原有 BootReceiver；通用热点仍使用 Android 系统授权和原有网络基础设施。

## 保留的共享能力

- 标准 CarPlay 协议、定位上报、地图虚拟流、地图浮窗与桌面共享。
- iAP2 来电解析和导航状态解析。`CarPlayCallState.kt` 中的 `CarPlayPhoneState` 只保存手机通话状态，不调用车辆服务；它继续支持通话期间的 Siri／媒体按键判断。
- ADB／无障碍等通用权限工具以及连接、媒体、方控诊断。
- 原有比亚迪协议数据结构和部分被共享代码引用的兼容接口。`BydNavigationOutputs` 的厂商输出接口现在不执行车辆操作，导航浮窗解析继续工作；`AmbientMusicController` 不创建灯光客户端或工作线程。

为避免升级时把旧版已暂停的蓝牙一直留在关闭状态，控制器保留既有蓝牙恢复日志的恢复路径；没有恢复日志时不为此连接 ADB。本版本不会再启动蓝牙暂停。通用 Wi-Fi 扫描恢复也保留。

## 验证范围

已运行真实源码的局部 JVM／Robolectric 测试：旧车辆设置失效、无灯光任务、手机来电与导航浮窗状态、Flyme 媒体发布／语音输入、Siri 映射、独立方控测试页及设置组件截图。

完整 Gradle CI 命令已尝试，当前环境无法写入用户 Gradle wrapper 的锁文件，因此未完成整包编译、完整测试套件或车机实测。需要在可正常构建的机器上继续验证普通版和 UID 版，并在车机复测连接、声音、Siri、焦点释放与方控。

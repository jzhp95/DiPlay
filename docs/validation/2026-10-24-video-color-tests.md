# 画面颜色测试 Tab 验证

入口：首页 → 测试工具 → 画面颜色。新增第 4 个 Tab，不改变原有方控、MFi、UID 页面。

- 14 个预设项目：8 个本地 H.264/HEVC、全/有限范围、TextureView/SurfaceView 组合；6 个真实 CarPlay 镜像的自动/全/有限范围与两种输出路径组合。
- 同一页提供原生近黑/近白/色条参照，临时 BT.709/BT.601 及亮度范围请求，原始画面/已保存画面调整对比。
- 逐项记录观察后自动下一项；无首帧不能记录颜色正常，无连接、不支持、跳过分别保留。可选任意项目补测。
- 每次观察持久化实际参数、观察结论、时间和唯一截图引用；保存文字报告并分享含 observations.json、fixtures.json、截图的 ZIP。
- 原始纹理采样不冒充面板测量；调整后窗口截图须完整可见，否则明确记录缺失。截图不能代表屏幕物理出光及后处理。
- 仅在明确开始后运行；换页、离开、配置重建停止测试；独立镜像不会替换正式首帧处理或正式格式记录。测试不写日常画面及输出设置。

验证：最终专项 16 项通过；shared 全量 1159 项无失败（1 跳过），Flyme EAS 10 项通过。完整 common 1315 项中有 99 项历史失败，与 2026-10-24 完整 UI 验证记录逐项比较，测试名与错误信息完全一致，无新增失败；完整 CI 仍返回非零，不宣称全量通过。Lint 0 错误、3 警告。APK 构建及签名校验通过，证书与之前 debug 包一致，minSdk28。

Android 9 / API28 的宽窄屏、大字体、RTL 自动化截图共 12 张；非实车截图，未在车机验证解码或色彩表现。四个内置视频已使用 ffprobe 检查色彩元数据，并解码检查色块中心，最大 RGB 误差为 1。

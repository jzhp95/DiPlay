# CarPlay 画面颜色测试

目标：在现有测试页面增加画面颜色 Tab，一次进入即可比较原生参照、标准视频及真实 CarPlay。

- [x] 测试先行：默认不覆盖颜色；仅诊断实例覆盖范围和标准；未渲染不能记录正常；结果按测试编号保留。
- [x] 生成同一 RGB 参照的 H.264/HEVC 全范围及有限范围测试片，记录生成命令和 ffprobe 元数据。
- [x] 复用 AndroidMediaSink；颜色覆盖仅由测试实例/测试镜像显式传入，主屏默认不变。
- [x] 新 Tab：原生灰阶、色条、两种输出路径、预设步骤、临时范围/矩阵、画面调整 A/B、记录和报告导出。
- [x] 退出/换页/重建停止测试并释放镜像与 Surface；报告持久化，普通设置不变。
- [x] API 28 行为测试、宽窄屏大字体及 RTL 截图、项目 CI 检查、独立审查并交付 APK。

限制：屏幕截图不能证明屏幕物理出光正确；主观观察与像素采样分别记录。不支持 HEVC或未连接 CarPlay 是未完成，不标记成功。

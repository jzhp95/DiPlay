# 清理比亚迪专用功能

目标：Flyme 版本不再提供或启动比亚迪专用车辆功能；保留 CarPlay 连接、MFi、音视频、Siri、Flyme EAS 方控、通用网络和诊断。

实现边界：删除专用设置和 Activity 入口；撤下比亚迪 HUD、仪表、车辆读取、电话音频和氛围灯运行入口。保留共享的 iAP2 导航与通话解析、通用副屏／地图浮窗、权限和网络基础设施。旧版偏好不得重新启用已删除功能。底层还被共享代码引用的兼容接口保留为不访问车机的实现，避免破坏上游合并和协议代码。

- [x] 移除设置、搜索中的专用项目，保留通用地图和网络项目。
- [x] 关闭旧配置恢复路径，切断厂商服务、ADB 车辆读写与氛围灯任务入口。
- [x] 清理独立的 UI／清单入口；保留通用协议与 Flyme 方控调用。
- [x] 添加旧配置回归验证，更新受影响测试，运行规定构建和可运行的局部测试。
- [x] 复核差异和残余调用；不提交、不推送，等待用户后续指令。

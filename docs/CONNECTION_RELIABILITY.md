# 连接可靠性验证

本分支最低运行版本为 Android 9 / API 28。排障以目标车机固件、权限、连接阶段和实际日志为准，不引用其他车型的历史结论作为适配保证。

- USB：确认端口和线缆支持数据传输，核对设备枚举、授权、认证及网络握手阶段；重连和关闭过程中不得复用失效请求。
- 蓝牙：区分发现、配对、RFCOMM 建立和首字节交换。系统显示已连接不代表 iAP2 可用。
- Wi-Fi：区分凭据下发、热点关联、IP 可达和后续会话建立；网络切换与协议超时分别记录。
- 音视频：同时检查网络接收、解码队列、播放时钟和界面生命周期，不能仅凭卡顿推断无线信号问题。
- 释放与恢复：分别验证拔线、关闭手机蓝牙/Wi-Fi、切后台、系统回收、再次连接及旧回调到达时的行为。

修改后记录构建版本、日志、重复次数及仍未实车验证的项。测试入口见 [TESTING.md](TESTING.md)，Android 9 Wi-Fi Direct 边界见 [ANDROID9_WIFI_DIRECT.md](ANDROID9_WIFI_DIRECT.md)。

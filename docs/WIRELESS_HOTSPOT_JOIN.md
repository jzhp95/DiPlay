# 热点自动加入排障

iPhone 收到热点凭据后仍可能没有完成关联。先区分手机未加入 Wi-Fi，与已加入后 CarPlay 会话没有建立，两者的排查方向不同。

1. 保持车机热点开启，核对应用中保存的名称、密码和实际配置一致。
2. 检查 iPhone 蓝牙、Wi-Fi 和该热点的自动加入状态，接受手机显示的连接提示。
3. 自动加入失败时，尝试在 iPhone 设置中手动加入同一热点。记录是否要求密码，以及手动加入后 CarPlay 能否继续建立。
4. 若手动加入也失败，检查热点频段、安全模式和车机系统配置；若能加入但无 CarPlay，检查后续 IP 可达、认证及会话日志。
5. 同一局域网模式需关闭路由器客户端隔离，详见 [EXISTING_WIFI.md](EXISTING_WIFI.md)。

Android 9 的 Wi-Fi Direct 能力边界与车机热点不同，见 [ANDROID9_WIFI_DIRECT.md](ANDROID9_WIFI_DIRECT.md)。不能用请求频道代替实际频率测量，也不能将其他车型的固件行为当作本车结论。

在诊断中记录目标车机固件、iOS、连接模式、失败时间和手动加入结果。分享前检查日志，不上传热点密码、认证文件或原始私人备份。当前设置入口见 [CONNECTION_SETUP.md](CONNECTION_SETUP.md)。
